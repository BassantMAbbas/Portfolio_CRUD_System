CRUD SYSTEM

A responsive CRUD web application that allows users to create, view, update, and delete records dynamically. The application stores data locally using browser localStorage, ensuring persistence even after refreshing the page.

Features:

Add new records (Create)
Display stored records in a structured table (Read)
Edit existing records (Update)
Delete individual records
Delete all records option
Data persistence using localStorage
Input validation
Responsive UI using Bootstrap

Technologies Used:

HTML5
CSS3
Bootstrap 5
JavaScript (ES6+)
localStorage

What I Practiced:

DOM manipulation
Working with arrays and objects
localStorage data persistence
Form validation
Event handling
Dynamic table rendering
